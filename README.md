# Digital Schedule

Система перегляду розкладу занять та обліку академічної успішності для студентів на платформі Android.

---

## Основні функціональні можливості

| Функція | Опис |
|---|---|
| **Розклад занять** | Перегляд розкладу на поточний і наступні дні з підтримкою горизонтальних жестів гортання (свайпів). |
| **Сітка розкладу** | Інтерактивна оверлей-таблиця розкладу з підтримкою масштабування, панорамування та перемикання тижнів (виклик натисканням на дату). |
| **Нотатки до занять** | Створення, редагування та видалення персональних заміток до конкретної пари на обрану дату з візуальним індикатором на картці. |
| **Автоматична синхронізація** | Авторизація та отримання актуального розкладу занять із кабінету студента НАУ. |
| **Ручне редагування** | Додавання, модифікація та видалення занять вручну через окремий екран редагування. |
| **Академічна успішність** | Отримання балів та підсумкових оцінок сесії за семестрами з можливістю розрахунку рейтингового бала. |
| **Персоналізація інтерфейсу** | Вибір акцентного кольору інтерфейсу за допомогою колірної палітри, шістнадцяткового коду (HEX) або регуляторів каналів RGB. |
| **Підтримка тем** | Світла та темна теми оформлення на базі Material Design 3. |
| **Конфігурація циклів навчання** | Підтримка однотижневого та двотижневого режимів навчання, а також гнучке налаштування суботніх занять. |

| **Обробка дат і часу** | ThreeTen Android Backport (ThreeTenABP) 1.4.5 |

## Встановлення та запуск

### Вимоги до середовища
- Android Studio (версія Ladybug / Hedgehog або новіша)
- JDK 11 або новіша версія
- Android SDK: мінімальна версія Android 7.0 (API 24, `minSdk = 24`), цільова версія — Android 16 (API 36, `targetSdk = 36`)

### 1. Клонування репозиторію

```bash
git clone https://github.com/your-username/DigitalSchedule.git
cd DigitalSchedule
```

### 2. Відкриття проєкту

Відкрийте кореневу директорію проєкту в середовищі Android Studio. Дочекайтеся завершення синхронізації Gradle.

### 3. Збирання проєкту

Для збирання налагоджувальної версії APK виконайте команду:

```bash
./gradlew assembleDebug
```

Для встановлення та запуску на підключеному емуляторі чи фізичному пристрої скористайтеся стандартним запуском у середовищі Android Studio або командою:

```bash
./gradlew installDebug
```

### 4. Первинне налаштування застосунку

1. Перейдіть до розділу **Налаштування** (третя вкладка на нижній панелі навігації).
2. У блоці конфігурації облікового запису введіть номер залікової книжки (логін) та пароль від [cabinet.nau.edu.ua](https://cabinet.nau.edu.ua).
3. Визначте параметри розкладу (однотижневий чи двотижневий цикл, статус суботніх занять).
4. Оберіть тему оформлення та акцентний колір.
5. Натисніть **Зберегти налаштування**.
6. На головному екрані скористайтеся кнопкою оновлення у верхній панелі для автоматичного імпорту розкладу занять або перейдіть до розділу **Оцінки** для завантаження академічних результатів.

## Структура проєкту

```
app/src/main/java/ua/zxcode/digitalschedule/
├── DigitalScheduleApp.kt   # Клас застосунку, ініціалізація ThreeTenABP
├── MainActivity.kt         # Точка входу в застосунок, навігація та управління темами
├── data/                   # Шар роботи з даними: Room БД, DAO, сховища та репозиторії
├── manager/                # Менеджери розкладу та часових інтервалів занять
├── model/                  # Доменні моделі даних (Lesson, Grade, ScheduleSettings)
├── parser/                 # Модулі автентифікації та парсингу даних кабінету
└── ui/
    ├── BottomNavigationBar.kt # Нижня панель навігації
    ├── components/            # Перевикористовувані компоненти (діалоги, картки, сітка)
    ├── screens/               # Екрани застосунку (HomeScreen, GradesScreen, SettingsScreen, EditScreen)
    └── theme/                 # Стилістика, типографіка, кольори Material 3
```
