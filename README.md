# 📅 Digital Schedule

> Мобільний додаток для студентів — автоматичний розклад занять та сесійні оцінки у кишені.

---

## ✨ Можливості

| Функція | Опис |
|---|---|
| 📚 **Розклад** | Зручний перегляд пар на тиждень із горизонтальним свайпом між днями |
| 🔄 **Автосинхронізація** | Автоматичне завантаження пар з кабінету студента в один клік |
| ✏️ **Ручне редагування** | Можливість додавати, змінювати або видаляти пари вручну через кнопку на головному екрані |
| 🎓 **Оцінки (Сесія)** | Завантаження балів з кабінету НАУ з перемиканням між семестрами |
| 🎨 **Кастомізація** | Повний вибір кольору акценту: інтерактивна палітра, HEX-код або RGB-повзунки |
| 🌓 **Теми** | Підтримка світлої та темної теми |
| 📆 **Гнучкий розклад** | Підтримка 1-тижневого та 2-тижневого розкладу з чергуванням, суботнього циклу тощо |

## 🚀 Quick Start

### 1. Клонувати репозиторій

```bash
git clone https://github.com/your-username/DigitalSchedule.git
cd DigitalSchedule
```

### 2. Відкрити проєкт

Відкрийте папку `DigitalSchedule` в **Android Studio**.

### 3. Зібрати та запустити

```bash
./gradlew assembleDebug
```

Або запустіть через **Run ▶** в Android Studio на емуляторі чи фізичному пристрої (Android 7.0+).

### 4. Перше налаштування

1. Відкрийте вкладку **Налаштування** (іконка ⚙️ на нижній панелі).
2. Введіть логін (номер залікової) та пароль від [cabinet.nau.edu.ua](https://cabinet.nau.edu.ua).
3. Налаштуйте тему, колір акценту та параметри розкладу (одно- чи двотижневий, суботи).
4. Натисніть **Зберегти налаштування**.
5. На головному екрані натисніть кнопку оновлення ↻, щоб автоматично завантажити розклад, або перейдіть на вкладку **Оцінки** (⭐).

## 📂 Структура проєкту

```
app/src/main/java/ua/zxcode/digitalschedule/
├── data/           # Room БД, SharedPreferences, DAO, репозиторії
├── manager/        # Логіка часу пар та розкладу
├── model/          # Data-класи (Lesson, Grade, ScheduleSettings тощо)
├── parser/         # Парсер розкладу та оцінок з cabinet.nau.edu.ua
└── ui/
    ├── BottomNavigationBar.kt # Нижня плаваюча панель (Оцінки, Головна, Налаштування)
    ├── components/            # Картки пар, оцінок, діалоги
    ├── screens/               # HomeScreen, GradesScreen, SettingsScreen, EditScreen
    └── theme/                 # Material3 кольори, теми
```
